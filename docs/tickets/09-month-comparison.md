# 09 — Month-vs-month comparison

**Depends on:** 04

## Description

Compare expenses between two months by category.

## Acceptance criteria

- [x] Own two month pickers, independent of the global range
- [x] Default: the last two months present in the file
- [x] Grouped bar chart by category (one bar per month) plus total difference in EUR and percent
- [x] Handles files with only one month (sensible message)
