# 07 — Category trend line chart

**Depends on:** 04, 05

## Description

A category's spending per month across the selected range.

## Acceptance criteria

- [x] Line chart with months on the x-axis, EUR on the y-axis
- [x] Category selector (one or several categories; default: all or top categories)
- [x] Respects the global month range; months with no spending show 0
- [x] German formatting
